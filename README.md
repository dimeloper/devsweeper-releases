# DevSweeper releases

Signed and notarized builds of [DevSweeper](https://devsweeper.com), a macOS menu bar app that finds the space
Xcode, simulators, package managers and coding agents leave behind, and rates what cleaning each item costs your work.

Download the latest version at **https://devsweeper.com/download/**. Installed copies update themselves.

This repository only hosts the release files. DevSweeper is proprietary software; the source code is not public.
